## Lỗi API xác nhận

`U13-H5`: `GET /api/mentor/meeting-reports/export.xlsx?term=SU26` với M1 trả HTTP **500** (`An unexpected error occurred`), không tải được XLSX. Log backend ghi `SixLabors.Fonts.FontException: No fonts found installed on the machine.` khi NPOI chạy `SheetUtil.GetDefaultCharWidth` qua `AutoSizeColumn`. Docker image hiện cài `postgresql-client-16` nhưng không có bộ font. Cần sửa image hoặc cách tính độ rộng cột, build lại, rồi test cả XLSX export liên quan. Chưa sửa code trong lượt kiểm thử này.
